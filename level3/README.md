# Level 3：经典网络学习（AlexNet、VGG、ResNet、U-Net）

## 学习目标
理解经典 CNN 从图像分类到图像分割的发展，为 Level 4 U-Net 项目打基础。

## 核心知识点

### AlexNet（2012）
- 深度CNN的开山之作，5层卷积+3层全连接
- 关键创新：ReLU激活（解决梯度消失）、Dropout（防过拟合）、数据增强

### VGG（2014）
- 核心思想：重复堆叠 3×3 小卷积核替代大卷积核（两个3×3 ≈ 一个5×3感受野，参数更少）
- 网络模块化：Conv-Conv-Pool 重复单元

### ResNet（2015）
- 关键创新：**残差跳跃连接**（skip connection）
- 让梯度能直接跳过若干层传播，解决了深层网络难训练的问题
- 使网络可以堆到上百层（Scaling）

### U-Net（2015）
- 用于图像分割/生成
- 结构：**编码器（下采样提取特征）→ 瓶颈 → 解码器（上采样恢复尺寸）**
- 关键：**跳跃连接**把编码器细节特征拼到解码器，保留边缘细节
- Level 4 手写擦除就是基于 U-Net
