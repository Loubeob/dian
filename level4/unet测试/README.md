# Level 4：U-Net 手写笔记擦除

## 项目目标
输入带手写答案/批注/演算的试卷图片，输出保留印刷文字、擦除手写的干净图片。

## 数据集
- 来源：团队提供的数据集（百度网盘）
- 结构：train（997张）/ val（124张）/ test（126张），每张含 input（带手写）和 target（干净）
- 预处理：prepare_data.py 划分数据集

## 模型：U-Net
- 编码器：下采样提取特征（64→128→256→512通道）
- 瓶颈：最深特征
- 解码器：上采样恢复原尺寸
- 跳跃连接：编码器特征拼接到解码器，保留细节

## 四代迭代（重点）
| 版本 | 方案 | Loss | 结果 |
|------|------|------|------|
| v1 | 256px、100轮 | 纯L1 | 模糊，PSNR 25.4dB |
| v2 | 512px、200轮 | L1+SSIM | 改良，~26dB |
| v3 | 残差掩码（输出1通道mask） | L1+SSIM+稀疏loss | ❌ 失败：模型偷懒输出全0 mask，什么都不擦，PSNR 11.9dB |
| **v4（最终）** | 512px、200轮、3通道输出 | **L1 + 0.1×SSIM + 0.1×VGG感知损失** | ✅ PSNR 27dB、SSIM 0.97，印刷字清晰 |

### v4 关键改进：VGG 感知损失
- 原理：用预训练 VGG19 网络提取图片特征，比较输出和GT在特征层的差异
- 效果：L1 只逐像素比较容易糊，感知损失逼模型保留印刷字的**结构和纹理**，所以印刷字清晰

### v3 失败教训（重要）
- 残差掩码方案思路：模型输出1通道 mask，output = input × (1 - mask)
- 问题：稀疏loss权重（0.01×mask均值）设太大，模型发现"输出全0 mask"损失最低
- 结果：PSNR 卡在 11.89dB，Mask图全黑 = 什么都不擦
- 教训：**损失函数设计比网络结构更关键**

## 超参数（v4）
| 参数 | 值 |
|------|-----|
| Epochs | 200 |
| Batch Size | 4 |
| 学习率 | 2e-4（Adam，CosineAnnealingLR） |
| 图片尺寸 | 512×512 |
| 损失权重 | L1:1.0 + SSIM:0.1 + VGG:0.1 |
| 梯度裁剪 | max_norm=1.0 |

## 改进方案思考（验收要求）
1. **GAN（Pix2Pix）**：加判别器做对抗训练，生成器输出更真实、笔迹擦得更自然
2. **Diffusion Model**：从噪声逐步去噪生成干净图，质量更高但训练更慢
3. **数据增强**：加入更多真实场景（不同光照、歪斜、彩色笔迹、模糊）
4. **更大数据集**：当前997张偏少，扩充可提升泛化
